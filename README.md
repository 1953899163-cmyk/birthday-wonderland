# Happy Pop · 生日游乐园

一个可离线打开的可爱生日主题网站，使用纯 HTML、CSS 与 JavaScript 实现。

## 直接体验

双击 `index.html` 即可打开。若要使用更完整的浏览器体验，也可以在当前目录运行：

```powershell
python -m http.server 8000
```

然后打开 `http://localhost:8000/`。

## 已包含

- 轻黏土与糖果派对视觉，支持草莓、晴空、抹茶三套主题
- 生日贺卡生成器，可自定义名字、年龄、祝福和卡片风格
- 吹蜡烛、拆礼物、许愿能量三个互动小游戏
- 按钮、开关、标签、进度、提示、头像组、弹窗等组件展示
- 彩带粒子、滚动揭示、蛋糕蜡烛、气球漂浮、卡片 3D 倾斜等动效
- 纯器乐音乐盒版《生日快乐》，无歌词演唱
- 键盘导航、可见焦点、减少动态效果和 390px 移动端适配

## 音乐文件

`assets/happy-birthday-instrumental.wav` 由 `generate_audio.py` 本地合成，不包含人声。浏览器通常会阻止自动播放，因此网站会自动尝试播放，也可以在页面底部或顶部点击音乐按钮开始播放。
